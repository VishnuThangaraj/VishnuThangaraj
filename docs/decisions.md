# VishnuOS Architectural Decisions (Task 0.6)

Locked decisions per Workflow v3:

| # | Question | Decision |
|---|---|---|
| **D1** | Hosting platform | GitHub Pages via GitHub Actions workflow |
| **D2** | Contact handling | Direct `mailto:` link with one-click clipboard copy feedback |
| **D3** | Public phone | Omitted from public profile for privacy |
| **D4** | Real URLs | Vishnu's GitHub (`https://github.com/VishnuThangaraj`), LinkedIn, Projects |
| **D5** | Resume format | Built-in Document Viewer with direct PDF download fallback |
| **D6** | Accent colour | Canonical GNOME Olive Green `#4b8501` (`rgb(75, 133, 1)`) |
| **D7** | Brand & naming | "VishnuOS", original logo and identity, inspired by GNOME / Ubuntu |
| **D8** | Wallpapers | Manifest-driven wallpaper system with neutral reference-calibrated background |
| **D9** | Visual styling | Strictly GNOME/Ubuntu Adwaita. No macOS Liquid Glass lensing or dock magnification |
| **D10** | Typography | Ubuntu typeface family (`@fontsource/ubuntu`) with Ubuntu Font Licence |
| **D11** | Icons | Original SVG icon set following Yaru symbolic aesthetic |
| **D12** | Theme defaults | Dark theme default matching R1–R5, instant light theme toggle, persistence |
| **D13** | Workspaces | 3 virtual workspaces matching indicator in R1 & R2 |
| **D14** | Network readout | Real browser connection readout with realistic baseline `8.8 KB/s` |
| **D15** | Audio | Silent by default; no unsolicited sound effects |
| **D16** | Cosmetic toggles | Bluetooth / Airplane mode clearly labeled cosmetic in Settings → About |
| **D17** | Migration path | Rebuild the visual presentation layer; preserve validated profile data and core store mechanics |
| **D18** | Reference gaps | Extrapolate light theme and unpictured apps using standard Libadwaita specs |
